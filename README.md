# Uçuş Paneli Tarayıcı Demosu

Gerçek uçuş kontrolü veya telemetri bağlantısı içermeyen simülasyon arayüzü.

```sh
python -m http.server 8000
```

http://localhost:8000/preview.html adresini açın. preview.html yerel kural tabanlı yanıtlar kullanır; harici yapay zekâ modeli değildir.

tb2_kontrol_paneli_system.html eski alternatif paneldir. Bu paneldeki kimlik doğrulamasız doğrudan API isteği kaldırılarak yerel demo yanıtına çevrildi.
kodlar.txt tarihsel metin taslağıdır; çalıştırma giriş noktası değildir. PDF belge ayrı tutulur.

JavaScript sözdizimi kontrolü yapılır; tarayıcıdaki tüm etkileşimler ve görsel düzen bu incelemede doğrulanmadı.
